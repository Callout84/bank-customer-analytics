Bank Customer Analytics & Churn Intelligence
Visão Geral

Este projeto foi desenvolvido com foco em análise de churn de clientes bancários utilizando conceitos de Analytics Engineering, Data Analytics e Storytelling com Dados.

O objetivo principal foi transformar dados brutos em informações estratégicas para apoiar possíveis decisões de negócio relacionadas à retenção de clientes, comportamento financeiro e segmentação analítica.

O projeto foi estruturado buscando aproximar o processo de análise de um cenário corporativo real, utilizando técnicas modernas de visualização executiva, SQL Analytics, Feature Engineering e construção de KPIs.

Objetivo do Projeto

Analisar padrões relacionados ao cancelamento de clientes (churn) em uma instituição bancária, identificando:

perfis com maior risco de evasão;
comportamento financeiro dos clientes;
impacto da atividade do cliente no churn;
diferenças entre segmentos demográficos;
métricas estratégicas para tomada de decisão.

Estrutura Analítica do Projeto

O projeto foi dividido em etapas comuns no fluxo de Analytics Engineering:

1. Data Ingestion

Carregamento e leitura do dataset bancário.

2. Data Quality

Verificação de:

valores nulos;
duplicados;
tipos de dados;
consistência das colunas.
3. Feature Engineering

Criação de novas variáveis analíticas:

faixa etária;
faixa salarial;
segmentação de clientes.
4. KPI Layer

Construção de métricas estratégicas:

taxa de churn;
saldo médio;
score médio;
clientes ativos;
salário médio.
5. SQL Analytics

Utilização do DuckDB para consultas analíticas em SQL diretamente no DataFrame.

6. Executive Visualization

Criação de dashboards e gráficos executivos utilizando:

Storytelling Visual;
Direct Labeling;
Hierarquia visual;
Cores intencionais;
Anotações analíticas.
Principais Análises Realizadas
Taxa de churn por país;
Churn por faixa etária;
Impacto da atividade do cliente no churn;
Correlação entre variáveis financeiras;
Segmentação de clientes;
Visualização executiva de KPIs.
Principais Insights
Clientes acima de 50 anos apresentaram maior tendência de churn;
Clientes inativos possuem risco significativamente maior de evasão;
Alguns segmentos financeiros demonstraram maior vulnerabilidade ao cancelamento;
O comportamento do churn apresentou relação com fatores demográficos e financeiros.
